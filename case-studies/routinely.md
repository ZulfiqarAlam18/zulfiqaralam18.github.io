# Routinely Project Description

## Overview
Routinely is a Flutter mobile application for habit tracking and todo management. It is built with an offline-first approach, local persistence via SQLite, and a modular GetX architecture. The project includes daily reporting, habit cycles, analytics, achievements, todo reminders, notifications, and data export/backup tools. This application is fully developed by the author.

## Tech Stack
- Flutter (Dart)
- State management: GetX
- Local storage: sqflite (SQLite), shared_preferences
- Notifications: flutter_local_notifications, timezone
- Charts: fl_chart
- Permissions: permission_handler
- Sharing/Export: pdf, share_plus, path_provider
- URL launch: url_launcher

## Core Features
- Habit cycles (weekly/monthly) with rules and daily reporting
- Streak tracking and achievements
- Analytics dashboard and cycle summaries
- Todo management with categories, priorities, due dates, and reminders
- Local notifications (daily reminders, assessment reminders, streak risk, weekly summary, todo reminders)
- Data export (CSV, PDF) and JSON backup/restore
- About Developer and Guidelines screens
